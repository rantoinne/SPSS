# Menu wireframe map (SPSS 30 Base structure)

Primary windows:

1. **Data Editor** — Data View | Variable View; status: Filter / Weight / Split  
2. **Syntax Editor** — run all / selection; problems + log  
3. **Output Viewer** — outline (Log, Notes, Warnings, Tables, Charts) + HTML content  
4. **Chart Builder** — gallery + drop zones  

Dialog chrome: **OK · Paste · Reset · Cancel · Help**

| Menu | Items (Base milestone) |
|------|-------------------------|
| File | New Dataset, Open CSV/SAV, Save CSV/SAV, Export Output HTML |
| Edit | Undo, Redo |
| View | Data/Variable tabs |
| Data | Sort, Select Cases, Weight, Split File (+ Aggregate/Merge/Restructure in engine) |
| Transform | Compute, Recode, Automatic Recode, Rank |
| Analyze | Frequencies, Descriptives, Explore, Crosstabs, T-Test, ONEWAY, Correlations, Regression |
| Graphs | Chart Builder |
| Utilities | Command history (session), Modules (Settings) |
| Window | Syntax / Output windows |
| Help | About StatDesk (original branding) |
